#Funções em Python

Neste desafio, serão praticados os principais conceitos relacionados à criação e utilização de funções em Python, desde as funções embutidas da linguagem até a criação de funções personalizadas e funções anônimas.

Conteúdos abordados
Compreensão e utilização de built-in functions (funções embutidas) do Python.
Criação de funções com e sem parâmetros de entrada.
Criação de funções com e sem retorno de valores.
Documentação de funções utilizando:
Type hints
Default values
Docstrings
Compreensão e criação de Lambda Functions (funções anônimas).
Objetivo

Desenvolver uma base sólida para trabalhar com funções em Python, compreendendo sua estrutura, reutilização, documentação e diferentes formas de implementação.

Este exercício faz parte da prática de fundamentos de Python para Data Science e Desenvolvimento.
